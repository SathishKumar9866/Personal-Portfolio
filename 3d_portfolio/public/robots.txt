# Everything here is open to everyone. `User-agent: *` below already says that,
# so the named blocks are redundant by the letter of the standard and deliberate
# anyway, for two reasons:
#
#  1. A named rule is where a future change goes. If one of these ever needs to
#     be turned off, the line already exists and the decision is one word, not a
#     research task about what the crawler is called this quarter.
#  2. Several of these tokens are not crawlers at all. `Google-Extended` and
#     `Applebot-Extended` control training use only and are read from robots.txt
#     with no fetching agent behind them, so a wildcard is not a clear answer for
#     them the way it is for a normal bot.
#
# The site wants to be read, indexed and summarised. See /llms.txt for the
# machine-readable copy, which is shorter than this markup and maintained by
# hand.
